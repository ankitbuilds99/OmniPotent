# ADR-0001: Record Architecture Decisions

## Status
Accepted

## Context
We need to record the architectural decisions made on this project to:
- Provide context for future maintainers
- Document the reasoning behind significant choices
- Create a searchable history of decisions

## Decision
We will use Architecture Decision Records (ADRs) as described by Michael Nygard.

ADRs will be:
- Stored in `docs/adr/`
- Numbered sequentially (0001, 0002, etc.)
- Written in Markdown
- Immutable once accepted (superseded by new ADRs if changed)

## Consequences
- New team members can understand historical context
- Decisions are documented before they're forgotten
- Requires discipline to write ADRs for significant decisions
